# Documentation & Support - Plugins Jeedom `alt-erre`

Bienvenue sur le dépôt public de **documentation**, de **suivi des versions (Changelogs)** et de **support (Issues)** des plugins Jeedom développés par **Aurélien Léovant (`alt-erre`)**.

> **Note :** Conformément à la licence des plugins `alt-erre`, le code source est hébergé dans des dépôts privés dédiés au déploiement sur le **Jeedom Market**. Ce dépôt public centralise toute la documentation utilisateur ainsi que le suivi des tickets (bugs et demandes d'évolution).

## Signaler un bug ou proposer une amélioration (Issues)

Vous pouvez ouvrir un ticket d'assistance directement dans l'espace **[Support & Issues GitHub](https://github.com/alt-erre/jeedom-docs/issues)** :

1. **[Signaler un bug (Bug Report)](https://github.com/alt-erre/jeedom-docs/issues/new?template=bug_report.yml)** : sélectionnez le plugin concerné dans le menu déroulant, indiquez sa version (ex. `0.1.0-beta.1`) et joignez les logs Jeedom en mode `Debug`.
2. **[Proposer une amélioration / Nouveau matériel (Feature Request)](https://github.com/alt-erre/jeedom-docs/issues/new?template=feature_request.yml)** : suggérez l'ajout d'une fonctionnalité ou la prise en charge d'un nouvel appareil.

Les tickets sont automatiquement catégorisés à l'aide des **labels par plugin** (`plugin:altAirCast`, `plugin:altAirMedia`, `plugin:altArlo`, `plugin:altBambuLab`, `plugin:altCambridgeAudio`, `plugin:altCellular`, `plugin:altDenon`, `plugin:altEducartable`, `plugin:altHue`, `plugin:altIos`, `plugin:altJvcProjector`, `plugin:altNetGuard`, `plugin:altNuki`, `plugin:altPlaystation`, `plugin:altPronote`, `plugin:altRoborock`, `plugin:altSamsungTv`, `plugin:altSiemens`, `plugin:altSocial`, `plugin:altSonos`, `plugin:altSportEasy`, `plugin:altSwitch`, `plugin:altTesla`, `plugin:altTransit`, `plugin:altTvDashboard`, `plugin:altTwinkly`, `plugin:altTydom`, `plugin:altXbox`) et **par canal** (`canal:beta`, `canal:stable`).
